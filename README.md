# 0xander Cryptography Toolkit

Ferramentas profissionais de criptografia em Python para:
- ASCII
- Cifra de César
- Fernet (criptografia de arquivos)

## Estrutura

```text
projeto_criptografia/
├── criptografia/
│   ├── __init__.py
│   ├── encriptador.py
│   ├── cifra_de_cesar/
│   ├── criptografar_arquivo/
│   └── descriptografar_arquivo/
├── README.md
└── requirements.txt
```

## Execução

```bash
cd projeto_criptografia
python3 -m criptografia.encriptador
```
